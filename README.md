# Eider Aldana — Academic Website

A bilingual (English/Spanish), multi-page academic website built with plain HTML, CSS and JavaScript.

## Files
- `index.html`: Home
- `about.html`: Academic profile
- `research.html`: Research
- `publications.html`: Publications
- `conferences.html`: Conferences and seminars
- `teaching.html`: Teaching
- `cv.html`: Curriculum Vitae
- `contact.html`: Contact
- `assets/profile.jpg`: Profile photograph

## Before publishing
1. Replace `YOUR_EMAIL@ubb.cl` in `contact.html` with your public academic email.
2. Add your ORCID and Google Scholar profile URLs in `contact.html`.
3. Add your CV PDF as `cv-eider-aldana.pdf` and link it from `cv.html`.
4. Verify dates and details on `conferences.html`.
5. Review all academic details and add any missing publications.

## GitHub Pages
Upload the contents of this folder to the root of a GitHub repository. In GitHub, open **Settings → Pages**, select the deployment source (usually `Deploy from a branch`), choose the `main` branch and `/ (root)`, and save. The site will be published at the GitHub Pages URL assigned to the repository.
